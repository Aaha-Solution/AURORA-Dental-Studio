## ✨ Overview

**AURORA Dental Studio** is a single‑page, editorial clinic website for a modern dental practice based in White Town, Puducherry, India. The centerpiece is a **photorealistic 3D tooth model** rendered in WebGL that reacts to cursor movements and choreographs dynamically with the scroll, wrapped in a calm, luxurious patient experience.

> ⚖️ **Indian Law Compliant:** Built in accordance with the **Dentists Act, 1948**, **Dental Council of India (DCI) Code of Ethics Regulations, 2014**, and the **Digital Personal Data Protection Act, 2023 (DPDP Act)**. Proprietary rights owned by **AAHA Solutions**.

## 🚀 Key Features

- 🦷 **Interactive 3D Hero** — Rendered with **React Three Fiber / Three.js**, warm enamel shading, soft studio lighting, damped cursor parallax, and smooth idle spin.
- 🎬 **Cinematic Scroll** — **GSAP ScrollTrigger** + **Lenis** smooth scrolling drive pinned sections, a horizontal clinic gallery, and 3D scroll choreography.
- 🧩 **Interactive Showcase** — Draggable **Before vs. After** smile makeover comparison slider (mouse · touch · keyboard), testimonials carousel, patient journey timeline, and FAQ accordion.
- 📋 **Appointment Booking Form** — Full Name, Phone, Email, Treatment selection, Preferred Time, and Preferred Date with validation and confirmation summary.
- 📱 **Fully Responsive** — Verified across mobile, tablet, and desktop viewports with zero horizontal overflow.
- ♿ **Accessible** — Semantic HTML, labelled controls, visible focus rings, and full `prefers-reduced-motion` support.
- 🔎 **SEO-Ready** — Dynamic metadata, Open Graph, Twitter cards, and `Dentist` JSON-LD structured data.

## 🏃 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node v20/v24)
- npm, pnpm, or bun

### Installation

```bash
git clone https://github.com/Ramanan-Prabakaran/AURORA-Dental-Studio.git
cd AURORA-Dental-Studio
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
